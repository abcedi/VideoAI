# Support

VideoAI is currently maintained as an early personal/open-source project. There is no guaranteed response time or commercial support agreement.

For normal help, use GitHub Issues:

https://github.com/abcedi/VideoAI/issues

Before opening an issue, check:

- [README.md](README.md)
- [docs/INSTALLATION.md](docs/INSTALLATION.md)
- [docs/USAGE.md](docs/USAGE.md)
- [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md)

Include relevant versions, source mode, reproduction steps, and sanitized error output.

Do not attach private media, account cookies, credentials, tokens, signed CDN URLs, or private source URLs.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md).
