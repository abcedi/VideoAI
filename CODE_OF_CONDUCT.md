# Code of Conduct

VideoAI is an early technical project where criticism and disagreement are welcome.

The standard is simple:

**Be direct about the work and respectful toward the people doing it.**

You are encouraged to question design decisions, identify bad code, challenge assumptions, propose competing architectures, ask for evidence, and suggest simpler solutions.

Not acceptable:

- personal attacks;
- harassment;
- threats;
- discriminatory abuse;
- doxxing/private-data disclosure;
- deliberately posting credentials or sensitive data;
- sustained disruption unrelated to the project.

Prefer:

> This function has unsafe quoting because...

over:

> Whoever wrote this is an idiot.

Repository maintainers may moderate participation as needed to keep discussion safe and useful.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) rather than publishing unpatched details.
